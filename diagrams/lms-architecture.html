Role surfaces

Student portal

Consume and submit

  • Materials, guides, media (17–19, 27)
  • Assignments (20), quizzes (24)
  • Marks / feedback (13, 28)
  • Timetable / attendance (11, 12)
  • Comms / live join (25, 26)

Lecturer portal

Publish and mark

  • Publish content & briefs
  • Receive / mark submissions
  • Attendance & live delivery
  • Workspace (CAP-44)
  • Class analytics (CAP-40)

Staff portal

Approve and assure

  • Material QA (CAP-43)
  • Copyright / IP (CAP-42)
  • Orientation publish (32)
  • Course evaluation ops (30)
  • ODL accreditation evidence (04)

Shared platform

Contracts and ops

  • Portal API + CAP-53
  • Auth / privacy (01, 39)
  • Mobile shell (36)
  • Monitoring / backup (37, 38)
  • Live file store (Q5)
BASE-44: a student Materials area alone is not a complete LMS — lecturer publish paths and staff assurance are required.
