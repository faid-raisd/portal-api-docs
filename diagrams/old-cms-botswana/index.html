4. DTEF scholarship → TEF.gov.bw

Botswana-specific government integration. Registry queues programme-of-study admissions; saving with status 31 (Sent by Registry) POSTs HAL+JSON to tef.gov.bw. Finance assist billing is a separate path (b_stdassist* / dtef_scholarship.

Gov API · Drupal HAL+JSON Table r_scholarshipapp CAP-48 adjacent No Cyberjaya equivalent

Sync sequence

Evidence: r_scholarshipappedit.php / r_dropout_scholarshipappedit.php (lists r_scholarshipapplist.php, r_dropout_scholarshipapplist.php).

  participant Edit as Scholarship edit

  Reg->>Edit: Edit row · set status 31 · Save
  Edit->>TEF: GET /rest/session/token
